# Security Policy

## Supported Versions
Only the latest public release is actively maintained with security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Trading Brain, please do **NOT** open a public issue.
Instead, send an encrypted security advisory or email directly to the project maintainers.
All security reports will be acknowledged within 24 hours.
